# 棚7 攻めの予防医療

**状態**：照合済み（2026年11月11日）。U.E.N.O.Planは厚労省の[概要資料](https://www.mhlw.go.jp/content/10901000/001727087.pdf)と[本文](https://www.mhlw.go.jp/content/10901000/001727090.pdf)（2026年7月23日公表）で、予防の持ち場の表は厚労省の健診制度の資料で照合した。0次予防の定義は一次資料に当てていない。

**一言で**：予防は「持ち場がばらばら」な分野で、健診は保険者、がん検診と予防接種は市町村、職場の健診は事業主、重症化予防は診療所が担う。「攻め」とは、本人の自主性だけに任せず、行政や保険者が能動的に介入して行動を変えるという意味。診療所と町は、その介入の最後の1メートルを担う。

**全体像：予防の段階と持ち場**

| 段階 | 中身 | 主な持ち場と根拠 |
| --- | --- | --- |
| 0次予防 | 環境や社会のしくみで、気づかないうちに健康になる | 国・県・市町村の健康増進計画（健康日本21）、まちづくり |
| 一次予防 | 発病を防ぐ（生活習慣、予防接種） | 市町村（定期接種の実施主体、予防接種法）、診療所 |
| 二次予防 | 早く見つける（健診・検診） | 保険者（特定健診、40〜74歳、高齢者医療確保法で義務）、市町村（がん検診、健康増進法の努力義務）、事業主（職場の健診、労働安全衛生法） |
| 三次予防 | 重症化・再発を防ぐ、機能を保つ | 診療所と病院、保険者の重症化予防（糖尿病性腎症など）、市町村の介護予防 |

境目にある仕組み：後期高齢者の保健事業は広域連合が持ち、介護予防は市町村が持つ。この二つを市町村でまとめて行う「保健事業と介護予防の一体的実施」が2020年4月からある（広域連合が市町村に委託する）。国保には、予防や健康づくりの取組を評価して交付金を配る「保険者努力支援制度」がある（市町村分と都道府県分。指標は特定健診・保健指導の実施率、がん検診受診率、重複・多剤投与への取組など）。

**U.E.N.O.Plan（攻めの予防医療）の要点**

- 目的は健康寿命の延伸と、社会保障を含む社会の支え手の拡大
- 名前は Understand・Exercise・Nourish・Optimize for Better Health の頭文字。今回は「第一弾」
- 重点は6領域：がん・循環器病等、歯科保健、リハビリテーション、栄養・食生活、認知症、性差に由来するヘルスケア
- 基盤は、データヘルスを土台にした「AI予防医療モデル」、個人インセンティブ、事業主と保険者の連携（コラボヘルス）
- 自治体と保険者への施策：歯周病検診を2027年度から10歳ごとから5歳ごとに広げる。簡易検査ツールを使う「簡易歯科健診」を2027年度から位置づける。職域を含めた受診状況の把握と受診勧奨を進める（本文の書きぶりは「要請」より「支援」「推進」が中心）
- 数値目標：5がん（肺・胃・大腸・乳・子宮頸）の検診受診率60%と精密検査受診率90%を令和10年度末までに（第4期がん対策推進基本計画の終期）、特定健診の実施率70%を令和11年度までに（概要資料にだけある）、歯科健診を過去1年に受けた人の割合95%を令和17年度までに

**会議・交渉で使う**

- 町の保健師や国保担当は、特定健診の受診率、重症化予防、がん検診などの指標を気にしている。保険者努力支援制度の評価と交付金に関わるから。「町の評価が上がる協力」は通りやすい
- 診療所が持ち込めるのは、「来院した人への健診・検診の勧め」と「精密検査の受診の後押し」。国の目標（精密検査90%）とつながる
- 「攻め」を言うときは「自己責任にしない、来ない人へ届ける」という意味で使う
- 避けること：予防で医療費が減ると断言する（短期の節約効果は分野により一様でない）。持ち場の違う相手にその場で結論を求める

**よくある誤解**

1. 「健診も検診も町の仕事」→ 特定健診は保険者ごと、がん検診は市町村、職場の健診は事業主。町が直接持つのは国保の加入者分とがん検診
2. 「予防すれば医療費は必ず減る」→ 分野による。予防の価値は健康寿命と生活の質で語る方が崩れない
3. 「攻めの予防は新しい事業を作ること」→ 当面の中心は、既にある健診・検診の受診率と精密検査の受診率を上げること

**自分の現場で確かめること**

1. 町の保険者努力支援制度で得点が低い項目と、診療所が手伝える項目：町の国保担当
2. 保健事業と介護予防の一体的実施を町がどう行っているか、医療側の役割はあるか：町の保健師
3. 糖尿病性腎症重症化予防プログラム（国の令和6年度版）の町での運用と、病院・診療所への紹介の流れ：町の保健師
