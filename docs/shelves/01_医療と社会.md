# 棚1 医療と社会

**状態**：照合済み（2026年11月11日）。厚労省・社人研・内閣府の資料で照合し、全国の数字を入れた。「過疎地で入院需要が山を越えつつある」は全国の一次資料では確かめられないので、町と圏域のデータで確かめる論点として残した。

**一言で**：日本の医療は、人口が増え若かった時代に作られた仕組み（皆保険・フリーアクセス・公定価格・民間主体の提供体制）で動いている。2040年に向けて、支え手と担い手が減り、高齢者の中でも85歳以上が増える。この前提のずれが、地域医療のほぼすべての論点の根にある。

**全体像**

| 仕組みの前提 | 中身 | 今ずれていること |
| --- | --- | --- |
| 国民皆保険（1961年） | 全員がいずれかの公的医療保険に入る | 保険料を払う現役世代が減り、高齢者の医療費の比重が増える |
| フリーアクセス | どの医療機関にも自分で選んでかかれる | 医師の地域・診療科の偏り。かかりつけ医の役割があいまい |
| 公定価格（診療報酬） | 価格は国が2年ごとに決め（薬価は毎年改定がある）、医療機関は値段を決められない | 物価・賃金の上昇に価格が追いつかず、費用だけが上がる |
| 出来高払いが中心 | 行為ごとに報酬が付く（入院はDPCなど包括払いも） | 量が収入になる。人口が減ると量が減り、固定費が残る |
| 提供体制は民間が中心 | 病院・診療所の多くは民間。公立は不採算の地域・分野を担う | 民間が撤退した地域で、公立が最後の受け皿になる |

人口の変化は地域で向きが違う。都市部は高齢者がまだ増えるが、過疎地では高齢者の数もすでに横ばいから減少に入り、医療需要の山を越えつつある所が多い（全国の一次資料では確かめていない。町と圏域の推計で確かめる）。減るのは外来と急性期の入院が先で、在宅医療・介護・看取りの需要は長く残る。

**暦**

| 時期 | 起きること | 区分 |
| --- | --- | --- |
| 2024年4月 | 医師の時間外労働に上限（医師の働き方改革） | 制度上は |
| 2025年 | 団塊の世代がすべて75歳以上に（2025年10月の75歳以上人口は2,127万人、17.3%） | 人口 |
| 5年ごと | 国勢調査（2025年10月実施）、将来推計人口（国立社会保障・人口問題研究所。最新は令和5年推計） | 統計 |
| 2040年頃 | 高齢者人口がほぼ山（ピークは2043年の3,953万人）。現役世代の減少が加速 | 人口 |

**会議・交渉で使う**

- 相手が気にしていること：首長と議会は住民の安心・雇用・財政、財政担当は繰出の膨らみ、住民は「近くに医者がいるか」
- 通る言い方：「2040年の町の年齢構成から逆算して、少ない人数で回る形に変える」「病院は町の大きな雇用でもある」
- 避ける言い方：「医療費の削減」だけを言う（住民の不安を招く）、「赤字だから縮小」（雇用と安心の話が抜ける）、「都会と同じように」

**よくある誤解**

1. 「高齢化で医療需要はどこでも増え続ける」→ 過疎地では高齢者数も減り、入院の需要は山を越えつつある所が多い（町の推計で確かめる）。増えるのは在宅・介護・看取りの比重
2. 「診療報酬を上げれば地域医療は救える」→ 単価が上がっても、患者数と働き手が減れば立たない。律速は人の確保
3. 「医師不足は数の問題」→ 全国の医師数は増えてきた（2024年末に34万7,772人、人口10万対280.9人）。問題は地域と診療科の偏り（偏在。棚4）
