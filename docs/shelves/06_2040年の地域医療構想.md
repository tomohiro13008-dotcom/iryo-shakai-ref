# 棚6 2040年の地域医療構想

**状態**：照合済み（2026年11月11日）。厚労省「[地域医療構想策定ガイドライン](https://www.mhlw.go.jp/content/10800000/001718620.pdf)」（2026年3月のとりまとめを受けたもの。発行日の記載なし）を読んで書き、法律の成立・公布日と医療機関機能報告の開始時期を確かめた。「会議・交渉で使う」のうち「私の整理」と書いた論点は、県の議論で確かめる。

**一言で**：2015年からの地域医療構想は「病床の数と機能」の話だった。新しい構想は2040年を見据え、外来・在宅・介護との連携・人材まで含め、各病院が「2040年にどの役割（医療機関機能）を担うか」を2028年度までに決める。自治体病院にとっては、新病院の形と役割を県の協議の場で確定させる手続きになる。

**全体像：5つの医療機関機能**

| 機能 | 担うこと |
| --- | --- |
| 高齢者救急・地域急性期機能 | 救急搬送の受入、入院早期からのリハビリと退院調整で、早く家に帰す |
| 在宅医療等連携機能 | 在宅医療の提供、24時間対応、在宅の患者の入院受入と後方支援 |
| 急性期拠点機能 | 手術や救急など医療資源を多く要する症例を集めて担う。災害医療や医師の教育も |
| 専門等機能 | 上に当てはまらないもの（集中的リハビリ、中長期の入院、有床診療所、特定の診療科など） |
| 医育及び広域診療機能 | 大学病院の本院が担う |

従来から変わる点：

- 病床機能の区分は、「回復期」と「高齢者などの急性期」をまとめて「包括期機能」にする。高度急性期・急性期・慢性期は残る
- 各医療機関は、今の機能、2040年に担う機能、診療実績を県に報告する（医療機関機能報告）。診療報酬の届出だけで機械的に決めない
- 構想区域は原則二次医療圏。ただし人口の少ない地域は、区域の中で入院を完結できなくなる前提で広域化を検討する
- 市町村は、自治体病院の開設者として病床と医療内容の見直しに協力し、介護保険の主体として介護保険事業計画との整合を図る。介護の課題を構想区域の協議で共有することが求められている
- 根拠は令和7年の医療法等の改正（令和7年法律第87号。2025年12月5日成立、12月12日公布。原則の施行は2027年4月1日）。医療機関機能報告は医療法30条の13に基づき、2026年10月から始まる

**暦**

| 時期 | 起きること |
| --- | --- |
| 2024年12月18日 | 「新たな地域医療構想に関するとりまとめ」（新たな地域医療構想等に関する検討会） |
| 2025年12月 | 改正医療法の成立・公布 |
| 2026年3月 | 同じ名前の「新たな地域医療構想に関するとりまとめ」（地域医療構想及び医療計画等に関する検討会）を、同じ月に社会保障審議会 医療部会が承認。ガイドラインはこちらに基づく |
| 2026年10月 | 医療機関機能報告が始まる（東京都の資料による。精神医療は2027年10月からの報告開始を見据えて検討中） |
| 2026〜2027年度上半期 | データ分析と構想区域の点検 |

| 2029年度頃 | 第9次医療計画の策定 |
| 2030年、2036年 | 必要病床数の見直し（医療計画の見直しに合わせる） |
| 2035年頃 | 成果の確保 |

**会議・交渉で使う**

- 町と病院にとっての意味：「2040年にどの機能を担うか」を、新病院の設計と同じ言葉で語れる。地域包括ケア病床を増やし在宅を支える方向なら、「高齢者救急・地域急性期」と「在宅医療等連携」のどちらを主にするかが論点になる（私の整理。県の議論で確かめる）
- 県と話すときは「構想区域の協議に、在宅と介護の現場の実情を出せる」という立ち位置が効く。ガイドライン自体が市町村に介護の課題の共有を求めている
- 第10期介護保険事業計画（2026年度策定）との整合が、町側の入口（棚4）
- 避けること：「病床削減の話」とだけ言う。住民と議会には「役割を決めて残るための手続き」として話す

**よくある誤解**

1. 「病床を減らすための構想」→ 病床数も扱うが、中心は2040年の役割分担。外来・在宅・介護連携・人材まで含む
2. 「県が決めて病院は従うだけ」→ 各病院が2040年の機能を報告し、構想区域の協議で決める。報告の中身を自分たちで考える余地がある
3. 「診療報酬の届出で機能が決まる」→ ガイドラインは届出だけで機械的に決めることを適切でないとしている
