# 棚5 病院とクリニックの経営

**状態**：照合済み（2026年11月11日）。総務省の公立病院経営強化ガイドラインと決算の資料で照合し、全国の数字を入れた。会計用語の定義は県の用語解説で確かめた。

**一言で**：収益は「患者数×単価」で、費用の大半は人件費を中心とした固定費。患者が少し減るだけで赤字に振れる。公立病院は公営企業会計で、本業の収支（医業収支）と繰入を含む収支（経常収支）を分けて見る。クリニックは固定費を院長が決められる分、損益分岐の患者数がすべてを決める。

**全体像**

| 観点 | 公立病院 | クリニック（無床診療所） |
| --- | --- | --- |
| 収益の柱 | 入院（病床数×稼働率×1日単価）、外来、救急 | 外来（再診・管理料）、在宅、検査 |
| 主な費用 | 人件費、材料費（薬・診療材料）、委託費、減価償却 | 人件費、家賃・リース、薬（院内処方なら）、システム |
| 単価を動かすもの | 施設基準と加算（看護配置、地域包括ケア、入退院支援など） | 管理料（生活習慣病管理料、地域包括診療料など）、在宅の点数 |
| 量を動かすもの | 病床稼働率、紹介と救急、平均在院日数 | 患者数、再診の間隔 |
| 会計 | 地方公営企業会計（発生主義・複式簿記）。毎年の損益（収益的収支）と投資・借入の返済（資本的収支）を分ける | 個人または医療法人の会計。院長の所得と経営が近い |
| 外から入るお金 | 一般会計からの繰入、補助 | 原則なし |
| 評価の物差し | 経常収支比率、医業収支比率、修正医業収支比率（繰入を除いた本業）、病床利用率、人件費・材料費の比率 | 損益分岐の患者数、1日の患者数、単価、人件費率 |
| 決める人 | 町長と議会（全部適用なら事業管理者も）。経営強化プランが物差し | 院長 |

押さえる考え方を三つ。

1. **損益分岐**：固定費 ÷（1 − 変動費の率）が損益分岐の収益。これを1人あたり単価で割ると、必要な患者数になる。「受診を減らしても黒字」の条件は、この式で確かめる
2. **利益と現金は別**：減価償却は現金が出ない費用、借入の返済は損益に出ない支出。赤字でも資金は回ることがあり、黒字でも資金が足りないことがある
3. **経営形態**：今の形は、地方公営企業法の一部適用、全部適用、地方独立行政法人、指定管理者の4つ。ガイドラインが挙げる見直しの選択肢は、全部適用、地方独立行政法人化、指定管理者制度、事業形態の見直し（民間譲渡、診療所・介護医療院などへの転換）の4つ。全部適用の自由度は独法より限られる。一部適用から離れるほど経営の裁量は大きくなる傾向があるが、一直線の序列ではない

公立病院経営強化プランは、総務省の「持続可能な地域医療提供体制を確保するための公立病院経営強化ガイドライン」（2022年3月29日）に沿って各病院が作る。対象期間は策定年度か次の年度から2027年度までが標準。中身は、役割・機能と連携、医師・看護師の確保と働き方改革、経営形態の見直し、新興感染症への備え、施設・設備（デジタル化を含む）、経営の効率化の6つ。経常収支比率と修正医業収支比率の数値目標は必ず置き、期間中の経常黒字化を目指す（難しければ時期と道筋を書く）。概ね年1回以上点検・評価して公表し、有識者や住民が入る委員会に諮る方式が示されている。

**会議・交渉で使う**

- 最初に「単価・量・費用のどれを動かす話か」を言うと、事務長と話が噛み合う
- 事務長・院長とは「修正医業収支比率」「病床利用率」「1日単価」「人件費比率」の4つで話す
- 町とは「経常黒字は繰入込みか」「本業の赤字をどこまで繰入で埋めているか」を共有する
- AIや業務改善の話は、「人件費を減らす」ではなく「時間外、外注費、医師を確保する費用」で語る
- 避けること：「赤字＝経営が下手」と断じる（政策医療の不採算は構造）。民間病院と同じ物差しだけで比べる

**よくある誤解**

1. 「経常黒字なら経営は健全」→ 繰入を含んだ数字。本業（修正医業収支）は赤字のことが多い。全国の公立病院の修正医業収支比率は80.9%（2025年度）
2. 「患者が増えれば必ず黒字」→ 人員基準や施設基準で人が要り、費用も増える。稼働と人員の組み合わせで決まる
3. 「赤字なら資金も尽きている」→ 利益と現金は別。資金繰りは内部留保と企業債の返済で見る
