# 棚4 医療・介護・福祉の制度

**状態**：照合済み（2026年11月11日）。厚労省の資料で照合した。2026年に入った新しい動き（介護報酬の臨時改定、医師偏在対策、医療DX）を書き足した。

**一言で**：国が法律と報酬（価格）を決め、県が医療の計画を作り、市町村が介護・保健・福祉を実施する。保険者は加入者の健康と給付に責任を持つ。計画は6年と3年の周期で回り、2024年度にほぼ一斉に新しい期に入った。2026年度は、3年の計画（介護、障害福祉、医師確保）がそろって次の期を作る年にあたる。医療と介護の境目（在宅医療、入退院、看取り）は、誰が持つかがあいまいになりやすい。

**全体像**

| 主体 | 主な役割 |
| --- | --- |
| 国（厚労省） | 医療法・健康保険法・介護保険法などの法律、診療報酬と介護報酬、計画の指針 |
| 都道府県 | 医療計画（医師確保計画と外来医療計画を含む）、地域医療構想、医療費適正化計画。国保の財政運営の責任主体（2018年度から）。保健所（政令市・中核市などを除く地域。町は県の保健所の所管） |
| 市町村 | 介護保険の保険者。地域包括支援センター、地域ケア会議、在宅医療・介護連携推進事業（地域支援事業の一つ。2018年度から全市町村で実施）。国保の資格管理・保険給付・保険料の決定と徴収・保健事業。母子保健、予防接種、がん検診、障害福祉 |
| 保険者 | 特定健診・特定保健指導（40〜74歳）、データヘルス計画 |
| 医療機関 | 病床機能報告、外来機能報告、かかりつけ医機能報告（毎年1〜3月、初回は2026年1〜3月）。新しい地域医療構想では医療機関機能報告（棚6） |

**会議・交渉で使う**

- 一番効くのは「今どの計画が策定中か」。2026年度は第10期介護保険事業計画、第8期障害福祉計画、後期の医師確保計画が同時に作られている。在宅医療・介護連携や入退院の連携を載せるなら、今年度が機会
- 在宅医療・介護連携は「日常の療養支援」「入退院支援」「急変時の対応」「看取り」の4場面で語られる（[手引き Ver.4](https://zaitakupf.mhlw.go.jp/assets/pdf/llgr6_75_tebiki.pdf)）。この言葉で話すと福祉側に通る
- 相手が気にしていること：福祉担当は介護保険料と給付の均衡、保健師は健診受診率と保険者努力支援制度の評価、県は計画どうしの整合
- 避けること：計画の策定が終わってから提案を持ち込む

**よくある誤解**

1. 「介護は福祉課の話で病院は関係ない」→ 在宅医療・介護連携推進事業は市町村の事業だが、医療側の参加を前提にしている
2. 「計画は形だけ」→ 計画に載らない事業には予算が付きにくく、載せ損ねると原則として次の期まで3〜6年待つ（中間見直しや毎年の予算で動く例もある）
3. 「県と町の役割ははっきりしている」→ 医療は県、介護は町が主で、在宅医療と入退院はその境目にある。境目は誰も持たないことが多い
4. 「介護報酬は3年に1度しか変わらない」→ 2026年6月に臨時改定があった

## 医療DX

**一言で**：保険証はマイナ保険証か資格確認書に一本化され、期限切れの保険証で受診できる暫定措置も2026年7月末で終わった。電子処方箋は薬局でほぼ行き渡ったが、診療所は3割ほど。電子カルテ情報共有サービスは2026年度冬頃の全国運用が目標。令和8年度改定で、DXの加算は「電子的診療情報連携体制整備加算」に作り直された。

| 項目 | 今の状況 | 出典 |
| --- | --- | --- |
| 従来の保険証 | 2024年12月2日に新規発行を停止、2025年12月1日に有効期限切れ。暫定措置は2026年7月31日で終了。8月からは「保険証を忘れた」と同じ扱い | [厚労省](https://www.mhlw.go.jp/content/12400000/001623080.pdf)、[大臣会見 2026年3月19日](https://www.mhlw.go.jp/stf/kaiken/daijin/0000194708_00907.html) |
| マイナ保険証の利用率 | 68.15%（2026年4月。病院68.50%、医科診療所71.16%、薬局63.29%） | [厚労省](https://www.mhlw.go.jp/content/12401000/001712851.pdf) |
| 電子処方箋 | 薬局91.8%、医科診療所32.2%（2026年9月、業界紙の集計）。義務ではない。医療機関向けの補助は2027年3月31日まで | [デジタル庁ダッシュボード](https://digital.go.jp/resources/govdashboard/electronic-prescription)、[日本医事新報](https://www.jmedj.co.jp/blogs/product/product_29438) |
| 電子カルテ情報共有サービス | 3文書（診療情報提供書、退院時サマリー、健診結果報告書）と6情報（傷病名、アレルギー、検査、処方など）を共有。全国の運用開始は2026年度冬頃が目標 | [内閣府 資料 2026年4月](https://www8.cao.go.jp/iryou/studygloup/20260410/pdf/s-1.pdf) |
| 電子カルテの普及 | 一般病院65.6%、一般診療所55.0%（令和5年医療施設調査）。2030年12月31日までに約100%が法定目標 | 同上 |
| 標準型電子カルテ | 医科の無床診療所向けの導入版を2026年度中に完成させる目標 | 同上 |
| 診療報酬の加算 | 医療DX推進体制整備加算と医療情報取得加算は廃止。電子的診療情報連携体制整備加算（初診時15・9・4点の3区分、再診時2点、入院初日160・80点）。マイナ保険証の利用率30%以上などが施設基準 | [岡山県 資料](https://www.pref.okayama.lg.jp/uploaded/attachment/410961.pdf)、[厚労省 令和8年度改定](https://www.mhlw.go.jp/stf/newpage_67729.html) |

- 会議で使う：「新しいDX加算のどの区分が取れるか」「電子カルテの更新時期に、共有サービスと電子処方箋の導入を合わせられるか」「補助の期限（2027年3月）に間に合うか」
- よくある誤解：「紙の保険証はまだ使える」→ 暫定措置も2026年7月末で終わった。「電子処方箋は義務」→ 義務ではない

## 医師偏在対策

**一言で**：2024年12月の「医師偏在の是正に向けた総合的な対策パッケージ」を受けて、令和7年改正医療法（令和7年法律第87号、2025年12月12日公布）ができた。2026年4月から、県が医師確保の重点区域を定め、外来医師過多区域での新規開業には事前の届出と要請の仕組みが入った。

| 仕組み | 中身 | 始まり |
| --- | --- | --- |
| 重点医師偏在対策支援区域 | 人口は残るのに医療機関が速く減る地域などを県が選ぶ。市町村や地区の単位でもよい。手当の増額（保険者の拠出）、診療所の承継・開業の支援、派遣元への支援が付く | 2026年4月1日 |
| 外来医師過多区域の新規開業 | 無床診療所は開設の6か月前に届出。県は夜間休日の初期救急・在宅医療・公衆衛生などを担うよう要請できる。応じなければ医療審議会での説明、勧告、公表、保険医療機関の指定期間の短縮（6年→3年など）。禁止ではない | 2026年4月1日 |
| 保険医療機関の管理者要件 | 一定の保険診療の経験を求める。地域医療支援病院などの管理者に求める医師少数区域等での勤務経験は6か月から1年に | 施行日は未確認 |
| 医師確保計画の後期 | 2027〜2029年度分を県が2026年度に策定中。後期ガイドラインは2026年6月公表 | 2027年4月 |

- 会議で使う：「町は県の重点区域の候補に入っているか」「後期の医師確保計画に町の病院・診療所を支援の対象として載せられるか」「承継・開業の支援の対象になるか」
- よくある誤解：「開業規制ができた」→ 禁止ではなく、届出・要請・勧告・公表の段階的な仕組み。「医師確保計画は6年」→ 3年ごと（医療計画の6年の中で前期と後期）
