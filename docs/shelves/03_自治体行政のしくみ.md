# 棚3 自治体行政のしくみ

**状態**：照合済み（2026年11月11日）。地方自治法・地方公営企業法・総務省資料で照合した。経験則の記述には「経験則」と書いた。

**一言で**：町は首長と議会がそれぞれ住民に選ばれる二元代表制で、予算は首長が作り議会が決める。実務は課ごとの縦割りで、法律・条例・規則・要綱と国の通知で動き、年度の暦に乗らないものは動かない。

**全体像**

| 主体 | 役割 | 医療の話での意味 |
| --- | --- | --- |
| 首長（町長） | 予算の調製と執行（地方自治法149条）、職員の任免（172条）、規則の制定（15条） | 町立病院の開設者は町で、町長はその代表。一部適用なら病院の経営の最終権限を町長が持つ |
| 議会 | 条例・予算・決算の議決（96条1項）、一般質問（会議規則と慣行による） | 病院の予算や料金、条例は議会を通る。議員は住民の声の窓口 |
| 課（病院所管、保健福祉、財政、総務、企画など） | 所管ごとの事務 | 「誰の所管か」で話の行き先が決まる。課をまたぐ案件は誰も持たないことが多い（経験則） |
| 病院（地方公営企業） | 一部適用（財務規定等のみ）なら管理者の権限を町長が行う（地方公営企業法34条の2）。全部適用なら町長が任命する病院事業管理者が、職員の任免・給与・契約・予算原案の作成を担う | 経営の権限がどこにあるかが、経営形態で変わる。全部適用でも予算の調製と議案の提出は町長に残る |
| 都道府県 | 医療計画、地域医療構想、医師確保計画、自治医大卒の配置、市町村への助言。2026年4月からは医師確保の重点区域の設定も（棚4） | 医療の計画と医師の配置は県が握る |
| 国 | 法律、通知、財源（交付税・補助） | 通知と交付税の算定が町の動きを縛る |
| 一部事務組合・広域連合 | 後期高齢者医療広域連合（県ごとに全市町村が加入。高齢者医療確保法48条）、消防など | 町単独では決められない分野がある |

決まりの階層は、法律＞政令・省令＞条例・規則。条例（議会が決める）と規則（首長が決める）はどちらも法令に違反しない範囲で作る自主法で、所管が分かれる。両者がぶつかれば条例が優先すると解されている。その下に要綱・要領（行政内部の基準。議会は要らず、住民を法的に縛らない）がある。補助金の交付要綱など、実際には要綱で動く事業が多く、外からは見えにくい。

国の通知の多くは「技術的助言」（地方自治法245条の4）で法的拘束力はないが、実務はほぼ従う。ただし法定受託事務の「処理基準」（245条の9）は性格が違うので、通知がすべて助言というわけではない。

**暦**（多くの自治体では）

| 時期 | 起きること |
| --- | --- |
| 4月 | 人事異動、新年度の執行開始 |
| 6月 | 定例議会 |
| 9月 | 定例議会（前年度の決算認定。決算は次の通常予算を議する会議までに認定に付す） |
| 10〜11月 | 翌年度の予算要求 |
| 12月 | 定例議会（補正予算） |
| 1〜2月 | 予算の査定と内示 |
| 3月 | 定例議会（当初予算。町村は年度開始の20日前までに提出） |

定例会の回数は条例で決まり（102条）、通年会期を選ぶ自治体もある（102条の2）。

**会議・交渉で使う**

- 相手の言葉：「所管」「根拠（法令・要綱）」「予算措置」「前例」「公平性」「議会への説明」
- 通る進め方：根拠と所管を先に示す。担当者が上司や議会に説明しやすい一枚を渡す。予算要求の前に相談する。予算不要か既存の枠でできる「試行」から入る
- 通る言い方：「既存の予算の範囲で試行できるか」「議会で話すときの資料に使える形にする」
- 避けること：年度途中に大きな予算を求める。担当者個人の裁量を超える頼み。「医療の専門性」で押し切る

**よくある誤解**

1. 「町長が決めればすぐ動く」→ 予算は議会の議決が要り、定例議会は年4回が多い。要綱で動ける範囲かどうかで速さが変わる
2. 「担当者が『検討します』と言えば進む」→ 予算要求の締切と所管が合わなければ翌年度以降になる。担当者は2〜3年で異動することが多い（経験則）ので、話は文書で残す
3. 「国の通知は助言だから従わなくてよい」→ 法的拘束力はなくても、交付税や補助の要件と結びつき、実務はほぼ従う。処理基準のように性格の違う通知もある

**押さえる数字（枠）**

| 項目 | 意味 | 町の値 | 出典の場所 |
| --- | --- | --- | --- |
| 町の一般会計の予算規模 | — | 【要入力】 | 町の予算書・広報 |
| 財政力指数 | 基準財政収入額÷基準財政需要額の3年平均。高いほど自前の財源に余裕がある | 【要入力】 | [総務省 財政状況資料集](https://www.soumu.go.jp/iken/zaisei/jyoukyou_shiryou/h22/setumei.html) |
| 経常収支比率 | 毎年決まって出ていく経費に一般財源が食われている割合。高いほど自由に使えるお金が少ない | 【要入力】 | 同上 |
| 健全化判断比率（実質赤字比率、連結実質赤字比率、実質公債費比率、将来負担比率の4つ） | 財政の健全度。基準を超えると健全化計画が要る | 【要入力】 | [総務省 健全化判断比率](https://www.soumu.go.jp/iken/zaisei/kenzenka/index2.html)、町の公表資料 |
| 病院事業の資金不足比率 | 公営企業ごとの資金の不足の度合い | 【要入力】 | 同上 |

全国の平均と比べるときは、財政状況資料集の「類似団体」の値を使う（町の規模と産業構造が近い団体どうしの比較）。

**自分の現場で確かめること**

1. 病院と富診療所の所管課、担当者、その在任年数：事務長
2. 病院の経営形態と、経営の決定がどこで行われるか：経営強化プラン、事務長
3. 定例議会の月と、最近病院が一般質問で取り上げられた内容：町の議会事録
