# 医療と社会のレファレンス 中身 v1（7棚の知識）

Nov 11, 2026 · @Tomohiro Inoue

## 使い方

7つの棚を、それぞれのタブに分けた。このタブには、使い方、棚をまたぐ暦、照合の記録を置く。レファレンスのWeb版はこの文書を正として作る。

棚の一覧：棚1 医療と社会、棚2 お金のしくみと流れ、棚3 自治体行政のしくみ、棚4 医療・介護・福祉の制度、棚5 病院とクリニックの経営、棚6 2040年の地域医療構想、棚7 攻めの予防医療

各棚は同じ順で書く。

1. **状態**：照合の日付と、何で照合したか
2. **一言で**：会議で最初に言える要約
3. **全体像**：誰が・何を・どの財源で（表）
4. **暦**：いつ何が決まるか
5. **会議・交渉で使う**：相手が何を気にしているか、通る言い方、避ける言い方
6. **よくある誤解**
7. **押さえる数字（枠）**：全国の値は入れた。町・県の値は【要入力】として残し、自分で埋める
8. **自分の現場で確かめること**：答えは自分で書く
9. **降り先**：共通学習ツールの単元、統合アプリの基礎編
10. **この棚の照合に使った資料**

**状態**：全棚 照合済み（2026年11月11日）。厚労省・総務省・社人研・内閣府などの一次資料に当て、誤りを直し、全国の数字を入れた。一次資料で取れなかった点は県・業界紙の資料を使い、その旨を書いた。会議で数字や条文を言う前に、各棚の資料で確かめる。

「制度上は」は法令や国の通知で決まっていること、「多くの自治体では」は運用の傾向、「経験則」は一次資料では確かめられない現場の知恵。町ごとに違う部分は「自分の現場で確かめること」に回した。

## 棚をまたぐ暦

会議の前に、「今どの時期か」をこの2つの表で確かめる。

**1年の暦**（多くの自治体では）

| 月 | 町と議会 | 国と制度 | 病院 |
| --- | --- | --- | --- |
| 4月 | 異動、新年度 | 薬価改定の施行（毎年） | 新年度 |
| 6月 | 定例議会 | 診療報酬改定（本体）の施行（改定の年） | 施設基準の届出 |
| 7〜8月 | — | 普通交付税の決定（8月31日まで）、国の概算要求（8月末） | — |
| 9月 | 定例議会（決算認定） | — | 決算の認定 |
| 10〜11月 | 翌年度の予算要求 | — | 予算要求を出す |
| 12月 | 定例議会（補正） | 国の予算案、診療報酬の改定率（改定の年）、特別交付税 | — |
| 1〜2月 | 予算の査定・内示 | 診療報酬の答申（改定の年。令和8年度は2月13日） | 外来機能報告・かかりつけ医機能報告（1〜3月） |
| 3月 | 定例議会（当初予算） | 特別交付税 | 事業年度の終わり |

**複数年の暦**

| 年度 | 起きること |
| --- | --- |
| 2026 | 3年の計画がそろって次の期を策定（第10期介護保険事業計画、第8期障害福祉計画、医師確保計画・外来医療計画の後期）。新しい地域医療構想のデータ分析が始まり、10月から医療機関機能報告。診療報酬改定（本体6月、薬価4月）と介護報酬の臨時改定（6月）。4月から医師偏在対策の重点区域と外来医師過多区域の仕組み。7月末で期限切れ保険証の暫定措置が終了。U.E.N.O.Plan公表（7月） |
| 2027 | 改正医療法の原則施行（4月）。介護報酬改定、第10期介護保険事業計画が始まる。歯周病検診の拡大と簡易歯科健診。公立病院経営強化プランの多くが最終年度（病院ごとに確かめる）。電子処方箋の医療機関向け補助の期限（3月末） |
| 2028 | 診療報酬改定。新しい地域医療構想の策定と各病院の2040年の機能が決まる。がん検診60%・精検90%の目標年度（年度末） |
| 2029 | 第9次医療計画の策定。第4期医療費適正化計画と第3期データヘルス計画が最終年度。特定健診70%の目標年度 |
| 2030、2036 | 地域医療構想の必要病床数の見直し。2030年12月末に電子カルテ普及率約100%（法定目標） |
| 2035 | 健康日本21（第三次）の最終年度。地域医療構想の成果の確保 |
| 2040 | 高齢者人口がほぼ山（ピークは2043年）。85歳以上が増え、構想が見据える年 |

## 照合の記録

**v0から直した主な点**

| 棚 | 直したこと |
| --- | --- |
| 棚2 | 保険者に国民健康保険組合と船員保険を加えた。診療報酬の入金を「診療月の翌々月（請求は翌月10日まで）」に直した |
| 棚1・2・暦 | 診療報酬の施行月を「本体6月、薬価4月」に分けた。高齢者人口のピークを2043年と明記した |
| 棚3 | 経常収支比率の向きを直した（高いほど余裕がない）。健全化判断比率を4指標にし、資金不足比率を加えた。町立病院の開設者を「町」に直した |
| 棚4 | 2026年6月の介護報酬臨時改定（+2.03%）、第8期障害福祉計画、医師確保計画の後期を加えた。医療DXと医師偏在対策を書き足した |
| 棚5 | 点検・評価を「概ね年1回以上」に直した。経営形態の見直しに「事業形態の見直し」を加え、一直線の序列という書き方をやめた |
| 棚6 | 同じ名前の2つのとりまとめ（2024年12月と2026年3月）を書き分けた。「必要病床数の見直し」に直した |
| 棚7 | 「糖尿病性腎病」を「糖尿病性腎症」に直した。がん検診の目標を「令和10年度末」に直した |

**まだ確かめられていない点**

- 全国の85歳以上人口の2040年推計（社人研 令和5年推計）。結果表を開けなかった。[社人研の結果表](https://www.ipss.go.jp/pp-zenkoku/j/zenkoku2023/db_zenkoku2023/db_r5_suikeikekka_1.html)の表1-9Aで確かめる
- 同規模の公立病院の類似平均（50〜100床、100〜200床）。[総務省 病院経営比較表](https://www.soumu.go.jp/main_sosiki/c-zaisei/hospital/kessan-bunseki/R06.html)の原表で確かめる
- 電子処方箋の病院の導入率、改正医療法の管理者要件の施行日
- 地方自治法の一部の条文（149条、172条、211条、233条、245条の4）は条番号を二次資料で確かめた。e-Govで原文を確かめると確実
