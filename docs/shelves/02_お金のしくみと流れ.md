# 棚2 お金のしくみと流れ

**状態**：照合済み（2026年11月11日）。厚労省・総務省の資料で照合し、全国の数字を入れた。診療報酬の入金日そのものは一次資料で確かめていない（請求期限は確認済み）。

**一言で**：医療のお金は「保険料・公費（税）・自己負担」の3つの財布から集まり、診療報酬という公定価格で医療機関に払われる。公立病院にはこれに加えて町の一般会計から繰出金が入り、その一部は国の地方交付税で町に手当てされる。

**全体像**

| 誰が | 誰へ | 何を | 補足 |
| --- | --- | --- | --- |
| 加入者・事業主 | 保険者 | 保険料 | 保険者は国保（都道府県と市町村、国民健康保険組合）、協会けんぽ、健保組合、共済、船員保険、後期高齢者医療広域連合 |
| 国・都道府県・市町村 | 保険者 | 公費 | 国保と後期高齢者医療は給付費の約5割が公費。協会けんぽにも国庫補助（16.4%）がある |
| 現役世代の保険者 | 後期高齢者医療 | 支援金 | 75歳以上の医療費を現役世代が支える（後期高齢者医療の財源の約4割） |
| 患者 | 医療機関 | 自己負担 | 就学前2割、就学後〜69歳3割、70〜74歳2割、75歳以上1割（70歳以上は所得に応じて2〜3割）。高額療養費で月の上限がある |
| 保険者 | 医療機関 | 診療報酬 | 審査支払機関（支払基金、国保連）を通る。診療月の翌月10日までに請求し、入金はおおむね診療月の翌々月 |
| 町の一般会計 | 病院事業会計 | 繰出金 | 総務省の繰出基準（救急、不採算地区病院、へき地医療、附属診療所、建設改良費と企業債元利償還金の2分の1、院内保育所、経営基盤強化など）に沿う「基準内」と、それ以外の「基準外」がある |
| 国 | 町の一般会計 | 地方交付税 | 普通交付税と特別交付税。病床数に応じた分などは普通交付税、不採算地区病院やへき地医療などは特別交付税で措置される。使い道は町が決める一般財源 |
| 国・県 | 医療機関・町 | 補助金・基金 | 地域医療介護総合確保基金、へき地医療の補助、補正予算の支援金など。申請と報告が要る |
| 40歳以上・公費 | 介護保険（市町村） | 保険料と公費 | 介護報酬として事業所へ。医療とは別の財布 |

町から見ると、医療に関わる会計は3つある。一般会計（税と交付税）、国民健康保険特別会計（国保の給付。町立診療所をここで持つ町もある）、病院事業会計（地方公営企業）。お金の話は、まず「どの会計の話か」をそろえると崩れない。

**会議・交渉で使う**

- 財政担当と話すときは、繰出を「基準内か基準外か」「交付税で手当てされる分と町の持ち出し」に分けて話す。相手は「町の持ち出しがいくら増えるか」を見ている
- 新しいことを提案するときは「使える補助・基金があるか」「要求の締切に間に合うか」を先に調べておく
- 通る言い方：「基準内の経費として整理できるか」「補正予算の支援の対象になるか」「来年度の要求に間に合うか」
- 避ける言い方：「町が赤字を埋めて当然」。繰出を全部「赤字補填」と呼ぶこと

**よくある誤解**

1. 「繰出金は赤字の穴埋め」→ 基準内の繰出は、救急やへき地など収入で賄えない政策医療の経費を一般会計が負う仕組み。基準外の赤字補填とは分けて考える
2. 「交付税は病院に直接入る」→ 町の一般会計に入る一般財源。病院に回すかは予算で決まる
3. 「診療報酬が上がれば病院は儲かる」→ 報酬は人件費と材料費の原資。公定価格なので、物価と賃金の上昇を自分で価格に乗せられない
